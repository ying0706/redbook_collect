# Redbook Collect Chrome 插件

这是一个Chrome浏览器插件，用于提取小红书笔记内容并自动写入飞书多维表格。

## 功能特点

- 自动提取小红书笔记的标题、作者、正文、标签、点赞数、收藏数和评论数
- 支持将数据一键写入飞书多维表格
- 配置信息本地保存，无需重复输入
- 简洁美观的用户界面

## 安装方法

1. 下载本仓库的所有文件
2. 打开Chrome浏览器，进入扩展程序页面（chrome://extensions/）
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择包含本插件的文件夹

## 使用方法

1. 首次使用时，点击浏览器工具栏中的插件图标
2. 在弹出的窗口中填写以下信息：
   - 飞书多维表格 URL（从飞书表格页面复制）
   - App ID（从飞书开放平台获取）
   - App Secret（从飞书开放平台获取）
3. 点击"保存配置"按钮保存设置
4. 打开任意小红书笔记页面
5. 点击插件图标，然后点击"提取内容"按钮
6. 等待数据自动写入飞书表格

## 如何从飞书开放平台获取一个应用的APP ID和APP Secret
1.进入飞书开发者后台
2.创建一个企业自建应用，在“凭证与基础信息”页面获取APP ID和APP Secret；
3.在权限管理页面，授权云文档和多维表格权限：权限管理→开通权限→应用身份权限→云文档、多维表格→确认开通权限

## 如何创建写入小红书笔记内容的多维表格？
1.创建一个飞书多维表格，表头与插件提取的字段名一致：URL、标题、正文、作者、标签、点赞数、收藏数、评论数；“URL、标题、正文、作者”字段类型为“文本”，“标签”字段类型为“多选”，“点赞数、收藏数、评论数”字段类型为数字；
2.给这个创建好的多维表格添加上文的应用：点击文档右上角...→更多→添加文档应用→输入应用名称；

## 注意事项

- 确保飞书多维表格的列名与插件提取的字段名一致
- 飞书应用的权限需要包含多维表格的读写权限
- 飞书应用和多维表格必须在同一个企业/用户下
- 插件仅支持小红书笔记详情页

## 开发说明

- 使用 Chrome Extension Manifest V3
- 纯原生JavaScript开发，无需额外依赖
- 支持Chrome浏览器最新版本
